# D80. QuadrantGear 特征改用 Apache Hamilton 列级 DAG

- **编号**：D80
- **日期**：2026-11-05
- **代码**：`GolemQ/analysis/feature_flow.py`、
  `analysis/quadrant_jit.py::calc_quadrant_downrisk_major`、
  `cli/bootstrap.py::MIN_PACKAGES`
- **测试**：`GolemQ/test_cases/analysis/test_feature_flow.py`

## 背景

`QuadrantGear` 的 O 档（`QuadGear0`）需要 8 个输入列，其中：

- 60min / 15min / 日线四象限（`4QPwrln`、`4QPwrlnMin`、`4QPwrlnMaj`）、
  日线 MACD、60min MACD 都会被多条下游复用；
- `calc_quadrant_downrisk_major` 内部原本会**再跑一遍**
  `calc_four_quadrant_boost(annual=252)`，与 `QLevMACDLagD` 的日线输入重复；
- 手写链已经在 `pipeline/mainstream/pipeline.py::code_features` 与
  `examples/_quadrant_neg.py` 各拼一遍（平行实现只会分叉）。

目标：按需计算（只要 `QuadGear0` 就不算 `zDLagD`）、各频段只算一次、
有人持续维护，不自造计划/优化器。

## 决定

1. **采用 Apache Hamilton**（发行包 `apache-hamilton`，导入名仍是 `hamilton`；
   原 `sf-hamilton` / DAGWorks，2025-04 进入 Apache 孵化器）。版本门槛
   `1.90` 写进 `cli/bootstrap.py::MIN_PACKAGES`。
   - 不选 Polars LazyFrame：它看不见 `numba` / CZSC 这类 Python UDF 内部；
   - 不选 Dask delayed：粒度是 task，不是列，拿不到「列已有就跳过」；
   - 不选 graphtik：语义接近，但长期单人维护、版本停滞。
2. **节点名用 snake_case，存储别名留在帧内**。Hamilton 节点名必须是合法
   Python 标识符，`4QPwrln*` 不能当节点名；`QuadGear0` / `QuadGear0Bf`
   本身合法，由 `@extract_columns` 直接暴露。
3. **`calc_quadrant_downrisk_major` 增加可选 `feat_day`**（向后兼容）。
   `feature_flow.qd` 是唯一的日线四象限节点，`quad_downrisk_major` 复用它；
   日线四象限因此严格只算一次。旧的「不传 `feat_day`」路径行为不变。
4. **主力 leadout 默认 `fold=True`**（D73 的折叠法）。`ms60` / `ms_day` 各算一次，
   `MsLeadoutBfMaj` 由日线帧按日期贴回 60min，与图表既有口径一致。
5. **本模块不取数、不写库**。三个 OHLC 帧由调用方注入；
   `quadrant_gear_features()` 是示例/管线用的一次性入口。
6. **暂不开启跨运行缓存**（`Builder.with_cache()`）。单次 `execute` 内的
   「共享节点只执行一次」已由 DAG 保证；跨运行复用仍走 review 契约物化。
