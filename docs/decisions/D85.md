## 原式（4.4）

`GolemQ_old/analysis/base.py:2309`（`calc_omnipath_credit_scores`）：
`COST5_UPRISING_BEFORE = Timeline_duration(cond)`，cond 由四层组成：

```
RETURN_COST5 ∈ (0.00618, 1.68)
& [ stage/MACD/xgb echo/1K stage/Prophet 五组“启动前”条件 ]
& [ MA250 相对位置 / quadrant / linearreg / CVaR / M9T 周线 等多组条件 ]
& ~(M9T 周线 < -20 且 ZEN OLS 下行排除项)
```

massive 侧：`Cost5UprBfCmb` = 全市场（≤618）众数、`Cost5UprCnt`、`Cost5UprPre`。

## 本次只搬 L2（用户 2026-11-21 选）

模块 `analysis/cost5_uprising.py::calc_cost5_uprising_before`：

```
(RETURN_COST5 > 0.00618) & (RETURN_COST5 < 1.68)
& ((bstStgBf < max(MACD_CROSS_SX_BEFORE, MACD_CROSS_JX_BEFORE_MAJOR))
   | (bstStgBf < MACD_CROSS_SX_BEFORE_MAJOR))
```

* **MACD 零轴交叉**按旧树 `features/base.py:580-593` 现场算（**不是** compact 里
  同名的 `MACD_CROSS_SX_BEFORE` —— 那个是 DEA/DIF 死叉，不是同一个量）；
* `bstStgBf` 由 `stage < -0.00168` 现算（与 attach 同口径）；
* 丢掉 XGB echo / 1K stage / Prophet / 周线 M9T / OLS 分支与排除项。

## 契约/因果

* 纯函数，只吃 `RetCost5` / `MACD` / `macdMaj` / `stage`；缺列返回全 0；
* 截断对拍：前 5/8 根算出的值与全量同位置相同（无未来函数）；
* `chip_cost_by_day(..., with_return_cost5=True)` 从 `ChipDistribution_jit` 带出
  `RetCost5`（**不乘 adj**）；`compact._derive_major` 补 `macdMaj`。

## 原型结果（000711，2025-04-07 附近）

**不触发**：stage=2 → `bstStgBf` 是“距上次跌破最底带”的**大数**（~1,900），
永远不小于 MACD 交叉的小数；原式里能把它拉回来的 XGB echo / 1K stage /
Prophet 分支正是本次丢掉的。此外新树的 `RETURN_COST5` 只在
`ChipDistribution_jit` 内部、且 review 走的是**日线** chip（实测 000711
2024-10~2025-04 的 `RetCost5` 只有 0 / -0.0069，进不了 `(0.00618, 1.68)`）。
