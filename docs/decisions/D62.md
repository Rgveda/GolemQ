### 有意偏离老树

* 老树 `resample_multi_frequency_indices_func` 用 `.bfill()` 把**日终值
  回填到盘中**（lookahead）；本实现改为**因果**：盘中用上一交易日、

* `MPWR3_MED` / `MPWR3_MAJ_MED`：老树是「快照历史的中位数」；这里用
  `expanding(min_periods=1).median()`（因果近似），等有横截面统计后再对齐。

## 二、`--strategy compact`

* `pipeline/compact/pipeline.py::CompactPipeline(BasePipeline)`：
  读 60min（必需）+ day（默认），调用 `calc_compact_features`，**不落库**；
  返回逐码统计（rows / cols / rank 行数 / last / missing）。
* `cli/commands/compact.py`：**只需要 `--strategy compact`**。
  可选全局 `--eval`（scope / 代码，缺省 **fast**）。
  **没有命令专属开关**（用户 2026-10-21 明确：不要 `--compact-*`）——
  固定 60min + day + rank。
