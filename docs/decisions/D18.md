# D18. `--save` 的取值校验交给 **argparse `choices=`**（一处真相源）

- **编号**：D18
- **日期**：
- **索引**：[DECISIONS.md](../../DECISIONS.md) —— `grep D18 DECISIONS.md`，或直接开这个文件

**决定**（2026-10-09）：`--save <SOURCE>` 的合法取值由 `add_argument(choices=...)`
声明，**`run_save` 里不再手写第二遍校验**。

```python
parser.add_argument('--save', nargs='?', const='tdx', default=None,
                    type=str.lower, choices=('tdx', 'pytdx', 'qmt'), metavar='SOURCE')
```

**为什么**：手写那版报的是「错误: --save 只接受 tdx / pytdx / qmt，收到 'x'」
+ `exit 1`；argparse 给的是**标准 usage + `invalid choice`（退出码 2）**，
且可选值会**自动进 `--help`**。两处都写就是**两个真相源** —— 改一处忘一处。

**`type=str.lower` 是承重的**：老代码是 `str(args.save).lower()`，所以
`--save TDX` 一直能用。`type` 在 **choices 校验之前**生效，故行为不变 ——
去掉它会静默把 `--save TDX` 变成用法错误（实测四种情形：`tdxx` ✗2、`''` ✗2、
`TDX` ✓、裸 `--save` ✓）。

**连带简化**：`Command.is_set` 那个 `is not None` 特例随之取消 ——
`choices` 保证 `args.save` 只可能是 `None` 或三个非空值之一，**真值判据就够了**。
（`is_set` 这个扩展点保留，只是当前没有命令用到。）
