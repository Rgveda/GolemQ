  （1,883 码），14 列逐列缺失 0**；`--partial` 再跑返回空。

## 四、顺带修掉一个静默 bug

`partial_codes` 的聚合里字段引用写成了 `_MARKER` 字面量（缺 `$`）：

```python
{'$ifNull': [_MARKER, None]}          # ❌ 永远是字符串 'renkoSpriceD' ⇒ 恒非空
{'$ifNull': ['$' + _MARKER, None]}    # ✅
```

后果：`renko` 计数恒等于 `review` 计数 ⇒ `missing` 恒 0 ⇒ `--partial` **永远
选不出码**（但工具表面正常，只打印「没有代码」）。已修。
