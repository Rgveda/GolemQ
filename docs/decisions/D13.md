# D13. QMT / xtquant：**只删入口，代码保留**

- **编号**：D13
- **日期**：
- **索引**：[DECISIONS.md](../../DECISIONS.md) —— `grep D13 DECISIONS.md`，或直接开这个文件

**决定**（2026-10-08）：MiniQMT 停服后，`--xtquant-init` / `--xtquant-sync` /
`--xtquant-sync-daemon` 三条 CLI 入口与它们牵动的 `scheduler` 调用**删掉**；
`gateway/xtquant/*`、`datasource/qmt_source.py`、`QMT_*_ENABLED` 开关、
`realtime.py` 的 QMT 支路与 `--save-qmt` **原样保留**（它们已不再 import xtquant，
成为不可达代码）。

**理由**：用户明确「只删入口，代码留着」。保留的代价是零（xtquant 只在函数级 import，
不碰就不加载）；删掉的收益是**入口不再把人引向一条已死的路**。

> ⚠️ **`--save-qmt` 这个开关本身已被 D14 删除（2026-10-09）**，QMT 参考数据的
> 入口改为 `--save qmt`。本决定的其余部分（`gateway/xtquant/*` 与
> `qmt_source.py` 的代码保留、`QMT_*_ENABLED` 开关）仍成立。
