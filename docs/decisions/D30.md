# D30. 自检加 **`交易日历`** 节点：那张手维护的静态表也得有人看着

- **编号**：D30
- **日期**：
- **索引**：[DECISIONS.md](../../DECISIONS.md) —— `grep D30 DECISIONS.md`，或直接开这个文件

**用户 2026-10-10 定**：「bootstrap banner 中加入交易日历检查，交易日历小于当前日期，
标红点；末端在当年的年底且当前日期在 11月10日以前，标绿点；末端在当年年底、当前日期
在 11月10日以后，如果没更新下一年 ⇒ 标黄点」。

**为什么值得一个节点**：`TRADE_DATE_SSE`（`markets/StockCN/constants.py`，**8797 条、
1990-12-19 起、末端 2026-12-31**）是**手维护的静态表**，而全树所有「今天是不是交易日 /
上一个交易日是哪天」都读它（`kline_doc.alive_threshold`、`trade_days_between`、
`GQ_util_if_trade`…）。**它过期了不报错** —— 只让「今天」被静默判成非交易日，于是
**短路判据 / TTL / 调度全按错的日子走**。

**四档判据**（`cli/bootstrap.check_calendar`，纯函数、日期可注入以便测）：

| 情形 | 状态 | |
|:--|:--|:--|
| 末端 **< 今天** | **红** | 日历已过期 |
| 末端 = **今年年底**，今天 **<= 11-10** | **绿** | 正常：明年的安排还没到公布时候 |
| 末端 = **今年年底**，今天 **> 11-10** | **黄** | **该续下一年了** |
| 末端 **> 今天但 < 今年年底** | **黄** | ⚠️ **这一档用户没给，是我补的**：还能跑，但覆盖不够长 |
| 日历空 / 末端不是 `YYYY-MM-DD` | **红** | |

⚠️ **本节点不进 `ENV_GATE_NODES`** —— 红点也**不拦启动**（与 OS / 时区同级：那是
"你该管了"，不是"跑不动"）。

**实测（真机 2026-10-10）**：`('ok', '覆盖到 2026-12-31（8797 个交易日）')` ✓ 绿。

⚠️ **它会在每年 11-10 之后变黄** —— 那是**有意的提醒**。用例
`test_real_calendar_is_current` 在黄点时会 **skip 并说明原因**，免得日后有人误以为
用例坏了；真到了那天该做的是**续 `TRADE_DATE_SSE`**，不是改用例。
