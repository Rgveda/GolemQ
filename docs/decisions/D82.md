# D82. 比值列（`*D` / `*_DUMMY`）的分母 = **分子所在快照的 as-of 收盘**

- **编号**：D82
- **日期**：2026-11-16
- **代码**：`markets/StockCN/reality_save.py::asof_close`、
  `pipeline/review/steps/hour_extra.py::{asof_close_by_ts, renko_ratio_frame}`、
  `pipeline/review/steps/daily.py::day_sample_step`、
  `analysis/reality_attach.py`、`pipeline/review/runtime.py`、
  `tools/backfill_hour_extra.py --ratios-only`
- **测试**：`test_cases/pipeline/test_hour_extra_shared.py::TestAsofClose`、
  `test_cases/analysis/test_reality_attach.py::TestAsofClose`、
  `reality_save.asof_close` 的 doctest

## 背景

review 的 60min 行是**按日快照 + 逐 bar 对齐**：zen / 中枢 / Renko / `se` /
日族采样 / ChipDist 的**分子**都取自「≤T 的最后一个 15:00 快照」——盘中三根
（10:30 / 11:30 / 14:00）用的是**上一交易日**的值，15:00 那根用当日。

比值列（D49/D70）把这些绝对量存成 `÷ close`，但如果分母取**目标 bar 自己的
close**，同一份「上一交易日的特征」就会被 4 根 bar 各除一次：
盘中比值随价格漂移，且与 15:00 那根不可比。

2026-11-16 复审（F2/F8）在库里实测（000711，2025-11-20 ~ 12-15）：

| 列组 | 盘中 3 根是否同值 | 结论 |
|:--|:--|:--|
| 日族采样 18 列（`poly9MajD` / `m9tMajR` / …） | **0/18 天不同** | 已经是 as-of（`_day_row` 当时就 ÷ 快照日 close） |
| 60min 原生 10 列（`poly9D` / `rTrePrcD` / `prophet*D` / …） | **0/18** | 已经是 as-of（`native_by_day` 内部就 ÷ 快照 close） |
| **ChipDist 4 列**（`cost*PrzD`） | **12/18** | ✗ 分母是 bar close（且 F2 前连分子都是当日） |
| **Renko 价格 6 列**（`renkoSpriceD` 等） | **12/18** | ✗ 分母是 bar close |

## 决定

1. **比值列的分母 = 分子所在快照的 as-of 收盘**：
   - 15:00 行 ⇒ 当日 15:00 的 close；
   - 盘中行 ⇒ **最近一个 ≤ ts 的 15:00 bar** 的 close（= 上一交易日收盘）；
   - 日频行（00:00）⇒ 自身 close（日线 bar 的 close 就是当日收盘）。
2. 规则**只实现一份**：`reality_save.asof_close(close)`（纯函数，带 doctest）。
   生产侧 `hour_extra.asof_close_by_ts(ohlc)` 只是「ohlc → close 序列」的薄包装；
   attach / runtime / `fetch_reality_feat` 的**还原**也乘同一个锚点（否则
   `ratio × 当前 close` 拿不回分子的绝对价）。
3. `renko_ratio_frame()` 抽成 review 与回填工具共用（F8 重建依赖它）；
   ChipDist 仍走 `build_chip_frame` / `chip_ratios_from_abs`。
4. **存量重建**：`python tools/backfill_hour_extra.py --ratios-only --apply`
   （只 `$set` chip 4 + Renko 价格 6 共 10 列，不动其余字段）。
   其余 28 个比值列不需要重建 —— 它们本来就是 as-of。

## 影响

- 盘中 3 根的比值现在**完全相同**（与日表 15:00 值一致），15:00 那根切到当日；
- 还原（attach / runtime / 图表）在 60min 帧上必须用 as-of close：这是
  **修正**现有行为（此前 `poly9MajD × bar close` 在盘中是错的，差一两天价格幅度）；
- 日族（`*_reality_feat_day`）行为不变：行时间戳 00:00 ⇒ as-of = 自身 close。

## 弃案

- **把分母统一成 bar close**（即现状）：比值随盘中价格漂移，且与「分子不更新」
  的事实矛盾；同一根 bar 的 `cost*PrzD` 每天都变，跨日不可比。
- **落库存绝对价**：复权换挡断层（D49/D70 已否决）。
