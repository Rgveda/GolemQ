# D73. 主力派发（LEADOUT）指标：主力吸筹 6 列的镜像，用于下跌指示

- **编号**：D73
- **日期**：2026-10-27
- **索引**：[DECISIONS.md](../../DECISIONS.md) —— `grep D73`，或直接开这个文件

**背景**：用户 2026-10-27 提出「考虑研发
`LTT.MAINSTREAM_LEADIN_VAR5 / ENTRY / SHAKEOUT / BEFORE / x3_BEFORE / x5_BEFORE`
的反函数，在下跌时起指示作用」。

## 一、定义：镜像公式

老树（与新树 `calc_mainstream_feats`）的吸筹口径是：

```
VAR1 = REF((LOW+OPEN+CLOSE+HIGH)/4, 1)
VAR2 = SMA(ABS(LOW-VAR1),13,1) / SMA(MAX(LOW-VAR1,0),10,1)
VAR3 = EMA(VAR2,10)
VAR4 = LLV(LOW,33)
VAR5 = EMA(IF(LOW<=VAR4, VAR3, 0),3)
进场 = IF(VAR5>REF(VAR5,1), VAR5, 0)      洗盘 = IF(VAR5<REF(VAR5,1), VAR5, 0)
```

派发口径逐项镜像：

```
VAR2' = SMA(ABS(HIGH-VAR1),13,1) / SMA(MAX(VAR1-HIGH,0),10,1)
VAR4' = HHV(HIGH,33)
VAR5' = EMA(IF(HIGH>=VAR4', VAR3', 0),3)
派发   = IF(VAR5'>REF(VAR5',1), VAR5', 0)   反抽 = IF(VAR5'<REF(VAR5',1), VAR5', 0)
```

`BEFORE / x3 / x5` 的 KDJ_J 与 MACD 判据同步反向（`> 1e-3` → `< -1e-3`，
`> 1e-9` → `< -1e-9`），其余系数 `0.618 / 0.382 / 0.168 / 3 / 5 / 0.832`
**逐字保留**，方便与原指标并排比较。

## 二、实现（不复制公式）

`analysis/quadrant_jit.py`：

* 新增 `hhv`（`llv` 的镜像，带 doctest）；
* 抽出 `_mainstream_pressure(ohlc, side)`：VAR1..VAR5 **同一份算术**，
  `side='low'` 吸筹 / `'high'` 派发 —— 两族共用，避免平行实现分叉；
* 抽出 `_mainstream_before(...)`：`Timeline_duration` 的 BEFORE / x3 / x5 链，
  用 `rising` 翻转方向；
* `calc_mainstream_feats` 改为调用上述内核；**输出逐值不变**
  （老树对拍 `test_mainstream_feats` 仍通过）；
* 新增 `calc_mainstream_leadout_feats`，产出 6 列。

`models/alias.py::LTT` 新增（**新树自造**，老树没有）：

```
MAINSTREAM_LEADOUT_VAR5      = 'MsLeadoutVar5'
MAINSTREAM_LEADOUT_ENTRY     = 'MsLeadoutEntry'     # 派发
MAINSTREAM_LEADOUT_SHAKEOUT  = 'MsLeadoutSko'       # 反抽
MAINSTREAM_LEADOUT_BEFORE    = 'MsLeadoutBf'
MAINSTREAM_LEADOUTx3_BEFORE  = 'MsLeadoutx3Bf'
MAINSTREAM_LEADOUTx5_BEFORE  = 'MsLeadoutx5Bf'
```

命名沿用老树 `QUADRANT_POWERLINE_LEADOUT*` 的 lead-out 习惯。

## 三、快速研究（16 码 × 60min，2020-01 ~ 2026-10）

触发后 5 / 10 根的平均收益（加权）：

| 信号 | 次数 | fwd5 | fwd10 |
|:--|--:|--:|--:|
| 原 `BEFORE` | 2,462 | +0.053% | +0.066% |
| 原 `x5` | 2,155 | **+0.091%** | **+0.139%** |
| 镜像 `BEFORE` | 2,025 | **-0.008%** | +0.064% |
| 镜像 `x5` | 1,467 | **-0.055%** | **-0.019%** |

结论：

1. 镜像方向正确（x5 转负），但 **edge 弱**，不足以单独作为下跌指示；
2. 原公式的 `ENTRY > close*0.618 / 3 / 5` 是**绝对价位量纲**，
   高价股几乎不触发 —— 600519 全样本 0 次，镜像同样 0 次；
   这不是镜像引入的问题，是老公式本身的量纲缺陷；
3. **接入 review 前需要先做阈值校准**（按 close/ATR 归一，或按 VAR5 分布分位数），
   否则高价股永远没有信号。

> **2026-10-29 校准尝试已撤回**：`Bf/x3Bf/x5Bf` 恢复为**逐字镜像 + 未校准**
> （用户 2026-10-29 决定）。不保留那次校准的口径（未成文，已撤回）；本文的镜像定义即当前代码口径。
> 后续方向改为**多级别扫描**：日线没触发就降级看 60min（再不行 15min）。

## 六、折叠法（2026-10-29 用户提出）

**问题**：`ENTRY`（VAR5）实测是**无量纲压力值**（中位数 ~20–30，p90 ~80–200），
而阈值 `close * 0.618` 是**绝对价位** —— 3.55 元阈值 2.2（天天触发），
300 元阈值 185（几乎不触发）。降级到 60min 也一样，量纲缺陷与频率无关。

**折叠**（用户口径）：股价 **> 10** 时取 `log10(close)`；**≤ 10 原值**
（「小于 10 用无系数算法」）。实现在 `quadrant_jit.fold_high_price`：

```
folded_close = close            , close <= 10
             = log10(close)     , close >  10
```

`_mainstream_before(..., fold=True)` 把公式里**所有** `close` 换成 `folded_close`
（含 `secondary > close*0.382` 那一支）。两个公开函数都接受 `fold` 参数，
**默认 `False`** —— 老树没有折叠，打开后与老树逐值对拍不再成立。

**验收（fold=True，±7 天窗口）**：

| 代码 | 目标 | 最近的 leadout |
|:--|:--|:--|
| 000711 | 2026-08-25 | 日线 x3 **08-25**；60min 08-24 |
| 000711 | 2026-09-02 | 只 08-26（目标之前） |
| 301308 | 2026-07-01 | 60min Bf/x3/x5 **07-01**；日线 x3 06-30/07-02/07-03 |
| 301308 | 2026-07-07 | 同上（07-03 后无新信号） |
| 601869 | 2026-06-25 | 60min Bf/x3/x5 **06-25**；日线 x3 06-26 |
| 601869 | 2026-09-18 | 日线 x3 **09-18**；60min x3 09-16/09-17 |
| 601869 | 2026-09-22 | 60min Bf/x3 **09-22**；日线 x3 09-21/09-23 |

⇒ 允许前后 ±7 天：**7/7**；严格「目标日或之后 7 天内」：**5/7**。
000711 09-02 与 301308 07-07 当天 `ENTRY = 0`（结构条件不满足），折叠救不了。

⚠️ `10 * log10(close)` 也试过：太严，301308 日线 x3/x5 全 0 ⇒ 不采用。
⚠️ `close == 10` 处不连续（10 → 1），是有意取舍。
⚠️ **字面写法 `log10(close) * ENTRY` 不是本实现**（2026-10-29 实测确认）：
它等价于 `ENTRY > close*0.618/log10(close)`，阈值只降 ~2.5 倍，
301308 全频率、601869 日线 x3/x5 仍 **0 次** ⇒ 高价股救不回来。
**用户 2026-10-29 确认：折叠作用在 `close` 价格侧即可。**
