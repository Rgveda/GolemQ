**判据的完整顺序**（短路那条链）：
① 盘中×分钟 ⇒ 禁跳 → ② TTL 未过期 → ③ 集合自证探针探到前沿 → ④ 该 code 水位 ≥ 前沿。
**四道缺一不可**，且**都偏向取数**（拿不准就取）。

**再改这一带时的纪律**：任何一条判据若要动，先答「盘中 / 收盘后各是什么答案」，
再答「答错那一侧会静默白扫、静默冻住、还是静默写错数据」——三者都不报错。
