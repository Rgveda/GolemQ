## 六、边角：`models/poolcoef.py` 的 fallback（解释清楚）

文件顶部有三段：

```python
try:
    from GolemQ.core.constants import AKA, FIELD as FLD
except ImportError:
    class AKA: ...          # 里面是假名
    class FLD: ...          # 里面是假名
```

- `GolemQ.core.constants` / `GolemQ.models.alias` 在树内**一定存在** ⇒ 这两个
  `except` 分支**永不会执行**，是死代码；但它们把列名写成了
  `MAINSTREAM_LEADIN_VAR5` 之类，若有人把模块单独拿去跑会**静默读错列**。
- **`PFL` 那段不同**：`GolemQ/portfolio/base.py` 在树内**不存在**，所以
  `except ImportError: class PFL: POSITION_LEVEL='POSITION_LEVEL'` 是**活的**。
  它给的是占位列名，不是真值。

⇒ 建议（下次清理）：删掉 `AKA/FLD/TRD/LTT` 三段死 fallback（直接 import，
失败就报错）；`PFL` 要么在 `portfolio/` 补真定义，要么在 `poolcoef` 未移植完
之前保留并标注占位。**不要只改 fallback 里的假名**。
