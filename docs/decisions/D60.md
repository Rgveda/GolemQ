# D60. CV 链迁出市场包；行情库句柄改由 `get_database()` 中性暴露

- **编号**：D60
- **日期**：2026-10-21
- **索引**：[DECISIONS.md](../../DECISIONS.md) —— `grep D60`，或直接开这个文件

**背景**：用户 2026-10-21 定：

1. CV 链不再留在 `markets/StockCN/chartscan/`，整体搬到 **`analysis/cv/`**；
2. **`markets.StockCN` 外部不暴露 `golemq_stock_cn`** —— 库名与句柄名只能出现在
   市场包内部，别处一律走市场对象的中性访问口。

---

## 一、搬迁

| 原位置 | 新位置 | 说明 |
|:--|:--|:--|
| `markets/StockCN/chartscan/client.py` | `analysis/cv/client.py` | 原 `__init__.py` 删除 |
| `markets/StockCN/chartscan/server.py` | `analysis/cv/server.py` | |
| `markets/StockCN/chartscan/predict.py` | `analysis/cv/predict.py` | |
| `markets/StockCN/chartscan/render.py` | `analysis/cv/render.py` | 内容不变 |
| `markets/StockCN/chartscan/model.py` | `analysis/cv/model.py` | |

同时：

* `analysis/cv/__init__.py` 重导出公开 API（`load_model` / `weights_path` /
  出图 / 预测 / 标记函数），`scopes` 仍留在包内；
* CLI（`cli/commands/chartscan.py`）、doctest 收集清单
  （`test_cases/test_doctests.py`）、`examples/app_chartscan.py` 的 import
  与 `python -m` 路径全部改到 `GolemQ.analysis.cv.*`；
* 两个用例模块按「被测层」从 `test_cases/markets/` 移到
  `test_cases/analysis/`；
* `D42` / `D44` 的旧路径加补记（历史不动，当前树以 `analysis/cv/` 为准）。

**为什么放 `analysis/`**：这条链是**跨市场**的（scope 解析本来就在
`analysis/cv/scopes.py`；出图/推理/协议与具体市场无关），留在市场包里会让根层
模块反向依赖市场包。A 股专有的只有两处输入：取数走市场实例、落库走注入的 `db`。

## 二、库句柄的中性访问口

新增：

```python
class StockCN(BaseMarket):
    def get_database(self):
        """行情库句柄 —— 市场包外部取库的唯一入口。"""
        return self.GOLEMQ_STOCK_CN
```

外部调用点全部切换：

| 位置 | 原来 | 现在 |
|:--|:--|:--|
| `analysis/cv/client.py` | `market.GOLEMQ_STOCK_CN` | `market.get_database()` |
| `analysis/cv/server.py` | `get_active_market().GOLEMQ_STOCK_CN` | `get_active_market().get_database()` |
| `cli/commands/watchlist.py` | 同上 | 同上 |
| `pipeline/review/pipeline.py` | 同上 | 同上 |
| `pipeline/review/runtime.py` | 同上 | 同上 |

`markets/StockCN/__init__.py` 的 `__all__` **不再导出**
`GOLEMQ_STOCK_CN` / `GOLEMQ_STOCK_CN_NAME`（定义仍保留，市场包内部模块照旧
用 `from . import GOLEMQ_STOCK_CN`）。CLAUDE.md 的「库名不外泄」硬规定同步改成
「别处一律 `get_active_market().get_database()`」。

⚠️ `reality_save.save_reality_feat` / `fetch_reality_feat` 的 `db=None` 默认
**只服务市场包内部**；pipeline / CLI / CV 必须显式传库实例。
