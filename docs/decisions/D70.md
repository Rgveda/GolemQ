# D70. 归一化价格列统一 `D` / `_DUMMY` 后缀；attach `* close` 还原无后缀价格

- **编号**：D70
- **日期**：2026-10-27
- **索引**：[DECISIONS.md](../../DECISIONS.md) —— `grep D70`，或直接开这个文件

**背景**：绝对价位一落库就会跟着复权因子过期；项目已有「÷close 存比值」的纪律
（D49/D53）。但历史命名不统一：`prophetLb` / `poly9Maj` / `garP` 没有后缀，
`poly9MajR` / `rTrePrcMajR` 用 `R`，而 `REGTREE_PRICE` / `POLYNOMIAL9` / `COST*`
在计算层仍是绝对价。用户 2026-10-27 定：

> 归一化 review 数据落库缩写加大写 `D`；归一化价格属性加 `_DUMMY`；
> attach 时 `_DUMMY / D * close` 还原无后缀的普通复权后价格。

## 一、命名规则

| 类别 | 规则 | 例子 |
|:--|:--|:--|
| **review 落库的归一化值** | 加大写 `D` 后缀 | `prophetLb`→`prophetLbD`、`poly9MajR`→`poly9MajD` |
| **feature/常量层的归一化价** | 常量名 / 列名加 `_DUMMY` 后缀 | `FIELD.POLYNOMIAL9_DUMMY='poly9D'`、`REGTREE_PRICE_DUMMY` |
| **无后缀** | **attach 还原后的普通复权后价格** | `prophetLb` / `poly9Maj` / `regtreePrice` / `garP` |

## 三、绝对价字段的 `_DUMMY` 输出

已新增常量（`FIELD`）：

```
POLYNOMIAL9_DUMMY='poly9D'             REGTREE_PRICE_DUMMY='regtreePriceD'
POLYNOMIAL9_MAJOR_DUMMY='poly9MajD'    REGTREE_PRICE_MAJOR_DUMMY='regtreePriceMajD'
COST5/15/85/95_PRICE_DUMMY='cost*PrzD' GARIDENT_PRICE_DUMMY='garPD'
```

生产者：

* `compact._base_frame`：`poly9D = poly9 / close`；
* `regtree_jit.calc_regtree_fractal_vXIs`：`regtreePriceD = regtreePrice / close`；
* `ChipDistribution_jit`：`cost*PrzD = cost*Prz / close`；
* `_coldstart_row`：`garPD = garP / anchor_close`（`garident_bands_to_ratio`
  已改为**先 `np.asarray` 再归一化**，落库仍转 list[tuple]）；
* `_day_row`：`poly9MajD / poly9WekD / rTrePrcMajD / rTreSlopMajD`。
* ⚠️ `REGTREE_PRICE_MAJOR_DUMMY` 常量已定义，但当前 compact 没有该绝对价列；
  对应的 major 归一化由 review 的 `rTrePrcMajD` 承载。

## 四、attach 还原

* `PRICE_RATIO_COLUMNS` 改为 D/DUMMY 名；
* `restore_price_columns` 不再原地改写，而是**新增无后缀 base 列**：
  `base = D/DUMMY 去掉后缀`，`base = dummy * close`；
* `garPD` 是**嵌套带**，单独用 `_restore_garident_bands`：
  乘的是 `garPAnchor` 那天的 close（**不是当前 bar**，D49 的硬约束）；
* `fetch_reality_feat(..., restore_price=False)` 在 attach 内先保留 D/DUMMY，
  最后统一还原；runtime/其它读口仍可自动还原；
* **attach 最终形态**：还原后 `_strip_price_suffix` **删掉 D/DUMMY 列**并同步
  `loaded`，features 里只保留 `prophetLb` / `poly9Maj` / `garP` 等无后缀价格；
  D/DUMMY 仍留在 MongoDB，不进入 attach 帧。

## 五、不重跑 review

full `--review` 会重算 STAGE/Garident/FBPROPHET，没必要。
