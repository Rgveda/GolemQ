# D64. 用户 CLI 与内部/调试入口分离

- **编号**：D64
- **日期**：2026-10-24
- **索引**：[DECISIONS.md](../../DECISIONS.md) —— `grep D64`，或直接开这个文件

**背景**：用户 2026-10-23/24 指出，很多 CLI 参数是「为了测试/试跑方便」加进来的；
现在**具体故障由 AI 智能体/测试来排查**，普通用户不再直接使用这些旗子。
它们出现在 `python -m GolemQ.cli --help` 里会让用户误以为那是正常操作的一部分
（例如 `--review-limit 10` 会**只写一部分数据**）。

---

## 一、两个入口

| 入口 | 用途 | 注册什么 |
|:--|:--|:--|
| `python -m GolemQ.cli` | **用户** | `commands/*.py` 的公开参数（`Command.internal_only=False`） |
| `python -m GolemQ.cli.internal` | **AI 智能体 / 测试 / 运维排障** | 公开参数 + `commands/_internal.py` + `internal_only=True` 的命令 |

`build_parser(internal=False)` 是唯一开关；`main(internal=...)` 透传。

## 二、收进 internal 的旗子/命令

**单旗子**（`commands/_internal.py`）：

* `--review-limit` / `--migrate-limit`
* `--save-collections` / `--save-start` / `--save-turnover-days` /
  `--save-margin-days` / `--save-progress-every` / `--save-jobs` /
  `--save-no-adj` / `--save-refresh`
* `--save-codes` / `--save-targets` / `--save-frequencies` / `--save-dry-run`
* `--moneyflow-dry-run` / `--migrate-dry-run`
* `--fill-turnover-codes` / `--fill-turnover-start` / `--fill-turnover-end`
* `--dry-run`（review）/ `--recheck-days`

**整条命令**（`Command.internal_only=True`）：

* `--save-coverage` / `--save-status`
* `--metadata-align`（及其 `-codes` / `-frequency`）
* `--review-runtime`（及 `--runtime-code` / `--runtime-as-of` / `--runtime-heavy`）
* `--migrate-turnover` / `--migrate-index-list` /
  `--migrate-metadata-merge` / `--migrate-metadata-verify` /
  `--migrate-reality-feat` / `--migrate-reality-verify`

⚠️ 触碰 4.4 的导入命令**尤其不能**出现在用户入口。

## 三、实现约束

* `run_*` 读内部参数一律 `getattr(args, 'xxx', default)` —— 测试用
  `SimpleNamespace` 直接调函数、不经过 parser 时也不会 AttributeError。
* `Command.matches` 本来就是 `getattr(args, f, None)`，用户 parser 缺这些
  dest 时命令自然不命中。
* 守卫用例：用户 parser 不得含 `INTERNAL_DESTS`；`--review-limit` 在用户
  parser 上必须 argparse 报错（不是「接受但隐藏」）。
* **新增 CLI 参数前先问「用户会不会用」**；只在测试/AI 排障里用的，注册到
  `commands/_internal.py`，不许进用户 parser（已写入 `CLAUDE.md`）。

## 四、验证

* 真机：用户 parser 的 29 个 dest 中，上述旗子/命令 **0 命中**；
  internal parser 67 个 dest 全部可解析。
* 全量 **985 条全绿**（skipped=1）。
* 历史决策/D44 等文档里对这些旗子的描述是其**当时**的用法；自 D64 起
  同一行为通过 `python -m GolemQ.cli.internal` 调用。
