# D58. Review CLI 参数语义：`--strategy review`（别名 `--review`）、全局 `--eval`、删除 `--daily`

- **编号**：D58
- **日期**：2026-10-20
- **索引**：[DECISIONS.md](../../DECISIONS.md) —— `grep D58 DECISIONS.md`，或直接开这个文件

**背景**：用户 2026-10-20 实跑 `python -m GolemQ.cli --daily`：

1. 没给 eval、没给 pct，命令**照跑** —— 代码里 `_eval_value()` 悄悄回落 `'fast'`；
2. Ctrl+C 无法停止（并行 worker 未终止，见 P39）。

同日进一步明确命令语义：**`--review` 就是 `--strategy review`**；
`--eval` 应与 `--review` / `--strategy` **正交组合**，不能自造
`--review-eval` 这种前缀变体（否则将来 `--strategy foo` 就得再造
`--strategy-eval`，同一语义出现多个名字）。

随后用户决定：**`--daily` 这个参数删除** —— 语义指向不明（它是模式？是命令？
还是日频开关？），不该作为可独立出现的入口。

---

## 一、决定

| 选项 | 语义 | 归属 |
|:--|:--|:--|
| `--strategy review` | 选择策略（当前仅 `review`） | **全局**（`cli/__main__.py`，dest=`strategy`） |
| `--review` | **`--strategy review` 的别名** | review 命令的命中开关 |
| `--eval` | `--strategy` 的**第二参数**：scope 或逗号分隔代码 | **全局**（dest=`eval_scope`），只注册一次 |
| `--force` | 忽略缓存/水位，强制重算或重探 | **全局**（dest=`force`），与 `--from` 可组合 |
| `--from` | 起始日期 `YYYY-MM-DD`（严格下界） | **全局**（dest=`from_date`），与 `--force` 可组合 |
| `--pct-of-cores` | 并行核数占比；未给时用 0.32 并在 stderr 明示 | review 命令自己的参数 |
| ~~`--daily`~~ | **已删除**（语义不明） | — |
| ~~`--review-codes`~~ | **已删除**（第二参数统一走 `--eval`） | — |
| ~~`--review-force` / `--review-from`~~ | **已删除**（改用全局 `--force` / `--from`） | — |

### 约束

1. **禁止前缀变体**：不再有 `--review-eval` / `--strategy-eval` /
   `--review-codes` / `--review-force` / `--review-from`；
   第二参数只有 `--eval`，通用修饰符只有 `--force` / `--from`。
2. **`--daily` 已删除**：argparse 直接拒绝（`unrecognized arguments`，退出 2）。
3. `--strategy review`（或 `--review`）**必须显式给第二参数**：
   `--eval <scope>` 或 `--eval <逗号分隔代码>`；没有 ⇒ 退出 2。
   **不再静默回落 `fast`**。
4. `--force` 与 `--from` **可组合**：`force` 只忽略已持久化，**不绕过** `from`
   （`--force --from 2026-09-01` = 从该日之后全部重算）。
5. `--pct-of-cores` 的 argparse 默认值改为 `None`，以区分「没给」：
   没给 ⇒ 用 0.32 + stderr 明示；显式给 0.32 ⇒ 不提示。
6. Ctrl+C ⇒ 打印「已中断」并退出 **130**（128 + SIGINT）；
   并行段改用 `with Parallel(...) as parallel`，由 `__exit__` 终止 worker（P39）。

---

## 二、兼容性

* `--review --pct_of_cores 32 --eval fast` 与
  `--strategy review --pct_of_cores 32 --eval fast` **等价**。
* `--scan ChartScan --eval fast --port 5555` 不变；ChartScan 改读 `args.eval_scope`。
* 老脚本里的 `--daily` **会报 unrecognized arguments（退出 2）** —— 这是刻意的：
  它原先的语义（模式修饰 / 可独立入口）不明确，删除好过猜。
* 老脚本里的 `--review-codes` 同样会被拒绝；代码请改放 `--eval`：
  `--strategy review --eval 600519,000001`。
* 老脚本里的 `--review-force` / `--review-from` 改为 `--force` / `--from`。

## 三、验证

* `TestReviewCliDefaults`（8 条）：`--daily` 被 argparse 拒绝（退出 2）；缺 scope ⇒ 2；
  `--review` 与 `--strategy review` 分发到同一命令；pct 默认明示 / 显式不提示；
  `--eval` 是唯一全局选项（无 `review_eval` / `scan_eval` / `review_codes`）；
  代码作为 `--eval` 第二参数；`--force` / `--from` 是全局修饰符且可组合；
  Ctrl+C ⇒ 130。
* `TestPipelineInterrupt`（1 条）：`KeyboardInterrupt` 必须走
  `Parallel.__exit__`（否则 worker 不终止）。
* `test_chartscan_cli` 改读 `args.eval_scope`，行为不变。
